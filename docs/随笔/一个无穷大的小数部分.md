# 一个无穷大的小数部分



## 题目

有没有自然数$n$，使得$\left(2+\sqrt{2}\right)^n$的值的小数部分大于$0.\underbrace{999\cdots9}_{100\text{个}}$？

## 分析

这是一个很有意思的题目。当 $n\to \infty$ 时 $\left(2+\sqrt{2}\right)^n$ 当然趋于无穷大。如果一个数的小数部分大于$0.\underbrace{999\cdots9}_{100\text{个}}$，那么它比之下一个整数相差的量就小于 $10^{-100}$ 了，这是一个非常小的正数。这让我们想到极限过程：题目是问，有没有自然数 $n$ 使的无理数 $\left(2+\sqrt{2}\right)^n$ 的值从小的方向（左侧）逼近于整数？不是说它逼近于某个固定的整数，而是逼近于整数这个形式：整数部分趋于无穷的整数，小数部分无限趋近于 $1$ （即 $.9999\ldots 9\ldots$ 任意多个 $9$ 这种形式）。

因此解决这道题目，需要对“极限”的定义有深刻的理解。在数学的学习中，深刻理解一个定义（概念），远远比掌握一个技巧重要的多。

试着将 $\left(2+\sqrt{2}\right)^n$ 二项展开看一下，它虽然没有极限，但是 $\left(2-\sqrt{2}\right)^n$ 却是无穷小。

## 解答

??? success "阅读详细解答"
    对$\left(2+\sqrt{2}\right)^n$二项展开：
    
    $$\left(2+\sqrt{2}\right)^n = C_n^02^n\left(\sqrt{2}\right)^0+C_n^12^{n-1}\left(\sqrt{2}\right)^1 + C_n^22^{n-2}\left(\sqrt{2}\right)^2 +\cdots + \left(\sqrt{2}\right)^n$$
    
    可以看出它的奇数项都是整数，而偶数项都是无理数。再考察 $(2-\sqrt{2})^n$ 的二项展开：
    
    $$\left(2-\sqrt{2}\right)^n = C_n^02^n\left(\sqrt{2}\right)^0-C_n^12^{n-1}\left(\sqrt{2}\right)^1 + C_n^22^{n-2}\left(\sqrt{2}\right)^2 +\cdots +\left(-\sqrt{2}\right)^n$$
    
    同样的，它的奇数项都是整数，而偶数项都是无理数，只是偶数项前的系数改变了符号。
    
    如果记 $\left(2+\sqrt{2}\right)^n$ 的所有奇数项的和为 $A_n$，所有偶数项的和为 $B_n$，那么 $A_n$ 是整数，$B_n$ 是无理数，于是：
    
    $$\begin{gathered}\left(2+\sqrt{2}\right)^n = A_n+B_n\\\left(2-\sqrt{2}\right)^n = A_n-B_n \end{gathered}$$
    
    由于 $0<\left(2-\sqrt{2}\right)<1$，因此 $0<A_n-B_n<1$，由于 $B_n$ 是无理数，因此成立：
    
    $$A_n=[B_n]+1\quad \implies \quad [B_n]=A_n-1 \label{sqrt2eq1}\tag i$$
    
    其中 $[B_n]$ 就是无理数 $B_n$ 的整数部分。这意味着，当 $n$ 增大时，$B_n$ 从左侧接近 $A_n$，并且可以达到任意指定的接近程度。
    
    由于$0<\left(2-\sqrt{2}\right)<1$，因此$\lim\limits_{n\rightarrow \infty}{\left(2-\sqrt{2}\right)^n}=\lim\limits_{n\rightarrow \infty}{(A_n-B_n)}=0$，那么根据极限的定义：任取$\varepsilon >0$，存在正整数 $N$，使得当 $n>N$ 时，有：$|A_n-B_n-0|=A_n-B_n <\varepsilon$ 恒成立。
    
    那么可取 $\varepsilon = 10^{-100}$，则存在正整数 $N$，使得当 $n>N$ 时，有：
    
    $$A_n-B_n<\varepsilon = 10^{-100} \label{sqrt2eq2}\tag {ii}$$
    
    根据式$\eqref{sqrt2eq1}$和式$\eqref{sqrt2eq2}$，无穷大 $\left(2+\sqrt{2}\right)^n$ 的小数部分的值即可表示为：
    
    $$\begin{aligned}\text{小数部分的值}&=A_n+B_n-[A_n+B_n]=B_n-[B_n]=B_n-(A_n-1)\\&=1-(A_n-B_n)>1-10^{-100}=0.\underbrace{999\cdots9}_{100\text{个}}\end{aligned}$$
    
    原命题得证。

## Pisot 数

这种“虽然本身趋于无穷大，但越来越逼近整数，小数部分无限趋近于1（即.999…9）”的现象，在数学中属于一个非常优美且专门的数论分支。

这类数字被称为 **Pisot-Vijayaraghavan 数**。
